# Intercom Enhancer

A Chrome extension that allows recording and sending audio messages directly from Intercom to users on the Help Desk.

I developed this extension to solve a problem faced by the help desk attendants at Amplifique.me, the company where I work. They needed a way to send audio messages to our customers, who frequently use audio. Brazilians love audio messages because of WhatsApp, and since Intercom doesn't support audio messages yet, I built this extension — and it works very well.

***Update:** We no longer use Intercom at Amplifique.me, so I'm not sure if this extension is still working, since it injects a button based on specific DOM elements, which can change at any time.*
